How I build agent systems

    
Pick a request and watch a simplified run of the kind of system I design: a planner splits the work, sub-agents call tools in parallel, and a reviewer checks the results before anything goes out.

Principles I build by

      
Draw the graph before writing prompts
An agent's behaviour lives in its state machine. I design the nodes, edges and checkpoints first, then the prompts.

      
Put data and tools behind MCP
Tools exposed as MCP servers can be reused by every agent and swapped without touching the agents themselves.

      
Infrastructure as code from day one
Queues, compute and secrets live in Terraform, so every environment can be rebuilt the same way.

      
Let agents check each other
A reviewer step that can send work back catches weak answers before a person ever sees them.
